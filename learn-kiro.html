¿Qué es Kiro?

Kiro es un IDE (entorno de desarrollo integrado) potenciado por inteligencia artificial, creado por AWS. Está diseñado para que desarrolladores y desarrolladoras de todos los niveles construyan software más rápido y con mayor calidad.

Combina un editor de código inteligente con un agente de IA que entiende tu proyecto completo: genera código, escribe tests, detecta errores y te guía paso a paso en la implementación.

🛠️ Capacidades clave

📋 Specs ⚡ Autopilot 🔧 Hooks 🧭 Steering 🤖 Agente IA 🧪 Tests automáticos
  • Specs — Define requisitos en lenguaje natural y Kiro genera un plan de implementación completo con requisitos, diseño y tareas.
  • Autopilot — Deja que Kiro implemente cambios de forma autónoma mientras tú supervisas y apruebas.
  • Hooks — Automatiza acciones del agente cuando ocurren eventos en el IDE (guardar archivo, crear test, etc.).
  • Steering — Guía al agente con reglas y contexto específico de tu proyecto para que siga tus estándares.
  • Agente IA — Un asistente que entiende tu código, responde preguntas y genera soluciones en contexto.
  • Tests automáticos — Kiro puede generar y ejecutar tests para validar tu código automáticamente.

🎓 Kiro en la Educación

🎓 Educación + IA

Kiro está transformando la forma en que los y las estudiantes aprenden a programar. En vez de quedarse atascados con errores de sintaxis o configuración, pueden enfocarse en entender conceptos y diseñar soluciones mientras la IA les ayuda con la implementación.

Esto permite:

  • Crear proyectos reales desde el primer día de clase
  • Aprender buenas prácticas de desarrollo de forma natural
  • Iterar más rápido y experimentar sin miedo a romper cosas
  • Entender arquitectura de software con la guía del agente IA

🚀 Crea un juego con un prompt

Con Kiro puedes generar aplicaciones completas a partir de una descripción en lenguaje natural. Aquí tienes un ejemplo real: el prompt que usamos para crear un juego estilo Pac-Man.

I want to build a Pac-Kiro game. Please create a basic working version with: - HTML5 canvas for rendering - A maze layout with walls stored as originalMaze template - Working maze copy that gets modified during gameplay - Dots to collect throughout the maze - Kiro-logo.png should be used as a character - A Kiro character (kiro-logo.png) with movement controls (arrow keys) that moves at controlled speed (8 frames between moves) - Simple ghost enemies that move slower than the player (12 frames between moves) - Basic collision detection for walls, dots, and ghosts - A score counter and lives system - Proper game state management with 'start', 'playing', 'gameOver', 'levelComplete' states - Start screen that shows 'Use arrow keys to move! Press any arrow key to start' - Game begins when any arrow key is pressed - Proper maze restoration on restart (copy from originalMaze, not random generation) - Movement timer reset on restart to prevent timing issues - Game over and restart functionality - Proper movement timing so characters don't fly around at jet speed Make sure movement is grid-based and feels like classic Pac-Man with proper timing. The maze must restore correctly on restart using the original template. Keep it simple and playable. Use vanilla JavaScript and make it work in a browser.

Copia este prompt, pégalo en el chat de Kiro y observa cómo genera todos los archivos del juego automáticamente.
