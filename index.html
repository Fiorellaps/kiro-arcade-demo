¿Qué es Kiro?

Kiro es un IDE potenciado por inteligencia Artifical (IA), diseñado para que desarrolladores de todos los niveles construyan software más rápido y con mayor calidad. Combina un editor inteligente con un agente de IA que entiende tu proyecto, genera código, escribe tests y te guía paso a paso.

🎓 Kiro en la Educación

Kiro está transformando la forma en que los y las estudiantes aprenden a programar. Los y las estudiantes pueden enfocarse en entender conceptos mientras la IA les ayuda con la implementación. Esto acelera el aprendizaje y permite crear proyectos reales desde el primer día.

Capacidades clave

📋 Specs ⚡ Autopilot 🔧 Hooks 🧭 Steering 🤖 Agente IA
  • Specs — Define requisitos en lenguaje natural y Kiro genera el plan.
  • Autopilot — Kiro implementa cambios de forma autónoma.
  • Hooks — Automatiza acciones en el IDE.
  • Steering — Guía al agente con reglas de tu proyecto.

🚀 Crea juegos con un prompt

Kiro puede generar aplicaciones completas a partir de una descripción en lenguaje natural. Aquí tienes un ejemplo real: el prompt que usamos para crear un juego estilo Pac-Man.

💬 Prompt: Pac-Kiro

I want to build a Pac-Kiro game. Please create a basic working version with: - HTML5 canvas for rendering - A maze layout with walls stored as originalMaze template - Working maze copy that gets modified during gameplay - Dots to collect throughout the maze - Kiro-logo.png should be used as a character - A Kiro character (kiro-logo.png) with movement controls (arrow keys) that moves at controlled speed (8 frames between moves) - Simple ghost enemies that move slower than the player (12 frames between moves) - Basic collision detection for walls, dots, and ghosts - A score counter and lives system - Proper game state management with 'start', 'playing', 'gameOver', 'levelComplete' states - Start screen that shows 'Use arrow keys to move! Press any arrow key to start' - Game begins when any arrow key is pressed - Proper maze restoration on restart (copy from originalMaze, not random generation) - Movement timer reset on restart to prevent timing issues - Game over and restart functionality - Proper movement timing so characters don't fly around at jet speed Make sure movement is grid-based and feels like classic Pac-Man with proper timing. The maze must restore correctly on restart using the original template. Keep it simple and playable. Use vanilla JavaScript and make it work in a browser.
